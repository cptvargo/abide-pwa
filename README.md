# 🌟 Overview

**ABIDE** is a handcrafted **Progressive Web App (PWA)** designed for serious Bible readers, students, and disciples.  
It blends Scripture reading, theological insights, ancient language tools, and personal reflection — all wrapped in an elegant mobile-first interface that works fully **offline** once installed.

This app is powered by the **VSV Translation**, a modern, original translation created by **Jesus Vargas**.

ABIDE aims to become **the most personal, devotional, and insightful reading experience** available on the web or mobile.

---

# ✨ Features

## 📖 **Scripture Reading Experience**

- Smooth scroll-based chapter reading
- Clean, high-contrast typography
- Beautiful verse numbering
- Intelligent floating navigation bar

## ✋ **Long-Press Verse Modal**

Open a verse-specific modal containing:

- Hebrew lexical data
- Theological insights
- Personal user notes
- Future: Cross-references, commentary layers

## 🌿 **Hebrew + Insight Engine**

- Hebrew lexicon stored locally in JSON
- Verse-by-verse insights (Genesis supported; expanding)
- Extensible to Greek and interlinear formats

## 📱 **PWA Offline Mode**

- Installable on **iOS, Android, and Desktop**
- Works offline once cached
- Seamless full-screen standalone mode

## 📝 **Note-Taking**

- Per-verse notes using localStorage
- Instant save on close
- Fully offline-capable

## 🎨 UI/UX Polish

- No text selection on iOS (prevents highlight interference)
- Smooth long-press detection
- TailwindCSS for consistent branding
- Dark-theme first approach (ABIDE gold + charcoal aesthetic)
